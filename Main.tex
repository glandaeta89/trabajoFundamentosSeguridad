\section{\large Emulación de un Ataque Log4Shell}

\subsection{Objetivo} 
El objetivo de este informe es realizar por medio de pruebas empíricas un laboratorio emulando un ataque de Log4Shell, desarrollando que el estudiante comprenda las herramientas y técnicas utilizadas en el proceso de la implementación de este ataque. Este ejercicio práctico tiene como finalizad profundizar el entendimiento de las vulnerabilidades y de seguridad de aplicaciones web y fomentar el desarrollo de habilidades técnicas para la identificación y mitigación de riesgos de ciberseguridad.

\subsubsection{Aspectos y Comandos Claves}
Para un desarrollador y una usuario de docker y Git existen varios aspectos claves dependiendo la necesidad del trabajo que se este realizando, para este laboratorio los comandos claves a utilizar seran los siguientes:

\begin{itemize}
    \item \texttt{docker exec -it my\_container \{comando de ruta u otro\}}: Con este comando podemos ingresar de modo interactivo a la terminal del contenedor donde podemos colocar alguna ruta en especial. Las más utilizadas son \texttt{/bin/bash}, \texttt{/bin/sh} y \texttt{ls}.
    \item \texttt{docker inspect}: Con este comando podemos inspeccionar todo lo que contiene el contenedor de Docker. Para este laboratorio se utilizará un comando un poco más especial para obtener la IP de cada contenedor inicializado. Este comando será el siguiente: \texttt{docker inspect -f '\{\{range.NetworkSettings.Networks\}\}\{\{.IPAddress\}\}\{end\}' \{nombre de contenedor o ID\}}.
    \item \texttt{docker ps}: Para verificar si el contenedor está en ejecución.
    \item \texttt{docker images}: Para verificar las imágenes contenidas localmente en Docker.
    \item \texttt{git clone \{url repositorio\}}: Para copiar localmente el o los repositorios que necesitemos.
\end{itemize}

\subsection{Levantar Aplicación Vulnerable-app} 
Para poder levantar la aplicacion seguiremos una serie de pasos para poder desplegar la aplicación que contiene la vulnerabilidad.

\subsubsection{Copia de Repositorio}
 Procederemos a copiar de forma local desde el repositorio de la aplicación Vulnerable-app, para esto necesitamos ejecutar el comando \textbf{git clone https://github.com/darryk10/log4shell-vulnerable-app.git}. Con este comando copiaremos de forma local el repositorio de la aplicación que contiene la vulnerabilidad.

\subsubsection{Construcción de la Aplicación}
Una vez descargado el repositorio debemos entrar a la carpeta del repositorio descargado y con el comando ls revisar el contenido del repositorio.

Desde la pagina del repositorio podemos verificar los pasos recomendados. En primer lugar recomiendan construir la imagen de la aplicación por medio del comando \textbf{\texttt{docker build . -t vulnerable-app}}. Se debe tener en cuenta que para construir la imagen debo tener un archivo receta Dockerfile dentro de la carpeta donde ejecutare el comando.

\subsubsection{Despliegue de la Aplicación}
Para el despliegue de la aplicación ejecutaremos el comando \textbf{\texttt{docker run --rm -d -p 8080: 8080 --name vulnerable-app vulnerable-app}}. Una vez ejecutado el comando se expondrá la aplicación en el puerto 8080.
